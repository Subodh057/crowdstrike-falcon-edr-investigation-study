# Project 2: High-Severity Chrome ML Detection Investigation

## Overview

This project is a screenshot-based CrowdStrike Falcon EDR case study focused on investigating a **high-severity Chrome-related machine learning detection**.

The goal of this project is to understand how a SOC analyst investigates a browser-related endpoint detection using detection details, file/hash evidence, process tree analysis, process activity, network operations, hash search, and response decision-making.

---

## Case Summary

CrowdStrike Falcon generated a high-severity detection related to:

```text
Triggering File: chrome.exe
Detection Type: Machine Learning via Sensor-Based ML
Severity: High
Status: New / In Progress
Verdict: Needs Investigation
