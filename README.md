# CrowdStrike Falcon EDR Investigation Study

## Overview

This repository is a screenshot-based CrowdStrike Falcon EDR investigation study focused on SOC/blue-team learning.

The main goal of this project is to understand how a SOC analyst works with an EDR platform during endpoint security investigations. This includes detection triage, severity-based prioritization, process tree analysis, hash search, host investigation, network activity review, containment decisions, and detection lifecycle management.

This repository is organized into multiple sub-projects, each focusing on one part of the CrowdStrike Falcon EDR workflow.

## Repository Objective

The objective of this repository is to build practical understanding of EDR investigation workflows, especially from the perspective of a beginner SOC analyst.

The project focuses on answering questions like:

```text
What happened?
Which endpoint was involved?
Which user was involved?
Which process triggered the detection?
How severe is the alert?
Is the activity suspicious or benign?
What evidence supports the decision?
Should the host be contained?
