# Project 1: CrowdStrike Falcon EDR Detection Triage Study

## Overview

This project is a screenshot-based CrowdStrike Falcon EDR study focused on the first stage of SOC/EDR investigation: **detection triage**.

The goal is to understand how a SOC analyst reviews the Falcon dashboard, checks endpoint detections, filters alerts by severity/status/triggering file, and decides which detection should be investigated first

---

## Project Objective

The objective of this project is to understand how SOC analysts perform initial triage in an EDR platform.

The project focuses on:

```text
- Reviewing the Activity Dashboard
- Checking new endpoint detections
- Prioritizing detections by severity
- Filtering detections by status
- Filtering detections by triggering file
- Sorting detections by detection time or last update
- Identifying new and unassigned detections
